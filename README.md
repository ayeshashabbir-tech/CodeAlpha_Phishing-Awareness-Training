# CodeAlpha_Phishing-Awareness-Training - Task 2

## 📌 Overview
This project is a Phishing Awareness Training module created as part of CodeAlpha Cyber Security Internship. The goal is to educate users on how to identify and avoid phishing attacks.

## 🎯 Objectives
- Explain how to recognize phishing emails and fake websites
- Educate about social engineering tactics used by attackers
- Provide best practices to avoid falling victim
- Include real-world examples and interactive quizzes

## 📂 Contents
- `phishing-awareness-module.html` - Interactive training module
- `Phishing-Awareness-Training.pptx` - Presentation

## 🛡️ Key Topics Covered
1. What is Phishing?
2. Types of Phishing (Email, Spear Phishing, Smishing)
3. How to Spot Fake Emails & URLs
4. Social Engineering Tactics
5. Prevention Tips

## 🚀 How to Use
1. Open `phishing-awareness-module.html` in any browser for interactive training
2. Open `Phishing-Awareness-Training.pptx` for presentation
